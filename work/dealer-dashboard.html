Portfolio Summary

This project focused on improving key experiences in a Dealer App used for managing auctions, orders, and transactions.

Through user research, usability testing, and data analysis, we identified major issues around lack of clarity, poor status visibility, and fragmented information across the system.

Key outcomes included a more structured order tracking experience, a unified dealer dashboard, improved system visibility, and better communication of system states.

Overall, the project improved clarity, reduced cognitive load, and helped users make faster and more confident decisions in a complex transactional environment.

Our Journey

My role focused on:

  • Identifying core user and business problems across critical flows
  • Designing clearer, status-based systems for orders and dashboards
  • Improving transparency while maintaining business data integrity
  • Reducing cognitive load through better information hierarchy
  • Creating actionable, easy-to-understand user experiences
