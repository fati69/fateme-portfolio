# Fateme Rafiyan — Portfolio

Senior Product Designer portfolio: [fateme-portfolio](https://github.com/fati69/fateme-portfolio).

## Local

```bash
cd archive-portfolio
npx --yes serve .
```

Or open `archive-portfolio/index.html` in a browser.

## Vercel

1. Import this GitHub repo in [Vercel](https://vercel.com/new).
2. Set **Root Directory** to `archive-portfolio`.
3. Framework Preset: **Other**. No build command.
4. Deploy.

Static files: `index.html`, `styles.css`, `animations.js`, `images/`, `fonts/`.
